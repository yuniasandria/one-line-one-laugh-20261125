A make.fun entry for [One Line, One Laugh](https://make.fun/c/u-plucky-finch-20-one-line-one-laugh-0ffe66ea): a program that writes one funny line of at most 200 characters to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

The line (160 characters):

> My microwave beeps 3 times when it's done, then again every 30 seconds until I open it — the only appliance in my house that files a noise complaint against me.
